نَسَق 3 — نسخة مستقلة تجريبية

التشغيل: افتح index.html في متصفح حديث؛ لا يحتاج إلى اشتراك أو خادم.
الملفات: index.html و app.js.

تنبيه مهم: هذه إعادة بناء تجريبية مستقلة وليست نسخة مطابقة لشيفرة Lovable أو لمحركه الأصلي. تحتوي على ستة أسئلة متتابعة، لا محرك التفرع الأصلي المعتمد. يجب ألا تحل محل النسخة الأصلية دون مراجعة واعتماد.

المنجز: العربية والإنجليزية، شاشة الدور والمجال، مساعدة بجوار الأسئلة فقط، خلاصة تحفظية، طلب مستشار دون اتصال خارجي، تقييم محلي اختياري، عداد مكتمل محلي للجهاز فقط.

غير المنجز: عداد إجمالي حقيقي مشترك بين الزوار (يتطلب قاعدة بيانات/خدمة)، نقل المحتوى ومحرك التفرع الأصليين حرفيًا، اختبار شامل مع مستخدمين، نشر على استضافة.

لا يتم إرسال الإجابات أو التقييمات أو الملاحظات إلى خادم، ولا تُحفظ الإجابات. يخزن المتصفح فقط عدد التجارب المكتملة على هذا الجهاز.
